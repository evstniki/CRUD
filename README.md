# CRUD App

This is a simple CRUD (Create, Read, Update, Delete) application built with React and TypeScript. The application allows you to manage a list of items, with functionality to add, edit, and delete items.

## Features

- Add new items
- Edit existing items
- Delete items
- Responsive and user-friendly interface

## Technologies Used

- React
- TypeScript
- UUID (for generating unique IDs)
- CSS (for styling)

## Installation

To get started with the project, follow these steps:

1. **Clone the repository:**

   ```sh
   git clone https://github.com/evstniki/CRUD.git
   cd CRUD

   ```

2. **Install dependencies**

   ```sh
   npm install
   ```

3. **Start the development server**

   ```sh
   npm run dev
   ```
